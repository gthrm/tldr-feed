# sources

Общий список источников. Его читают оба приложения — бот (`apps/bot`) и дневной
дайджест (`apps/daily-api`). Правится здесь, в одном месте, и меняется у обоих.

Логика у приложений своя: бот постит слотами в Telegram, дейли раз в вечер собирает
страницу и письмо. Общие тут только сами источники.

Путь к файлу каждое приложение берёт из `SOURCES_PATH`, а без неё — из этого каталога
по относительному пути. В образах структура каталогов сохраняется, поэтому работает
одинаково локально и в Docker.

Формат — см. `defaults` и комментарии внутри `sources.yaml`. В конце файла список
источников, исключённых намеренно, с причинами: он бережёт время, не удаляйте его.
